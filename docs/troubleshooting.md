# 트러블슈팅 (실운영)

실서비스를 빌드·배포·운영하며 진단하고 해결한 사례입니다. "무엇을 고쳤나"보다 **원인을 어떻게 좁혔나**를 남깁니다.

## 1. 로컬 서버 주소가 프로덕션 앱에 박힘 → 빌드 가드로 재발 차단

- **증상**: 라이브에 나간 빌드가 로컬 백엔드(LAN·http)를 가리켜 실사용자가 접속 불가.
- **원인**: Expo가 `.env.local`을 `.env`보다 우선 읽는다. 릴리즈 전에 `.env`를 운영으로 바꿔도, 개발용 `.env.local`의 로컬 IP가 덮어써서 번들에 박혔다.
- **해결**: 임기응변(그때그때 `.env.local` 비활성)에 기대지 않고, **Expo와 동일한 우선순위로 실제 값을 재현해 사설망이면 빌드를 실패시키는 가드**를 만들어 `app.config.js`·`build.gradle`에 물렸다. 이제 사람이 깜빡해도 파이프라인이 막는다. → [`api-and-build.md`](./api-and-build.md)

## 2. 릴리즈에서 어트리뷰션이 통째로 죽어있던 문제

- **증상**: 광고/리퍼럴 어트리뷰션 SDK가 릴리즈에서만 동작 안 함.
- **원인**: SDK 키(`EXPO_PUBLIC_*`)가 **개발용 `.env.local`에만** 있었는데, 릴리즈 빌드는 오배포 방지를 위해 `.env.local`을 비활성한다. 그래서 릴리즈 번들엔 키가 안 구워져 SDK가 빈 키로 초기화됐다.
- **해결**: `EXPO_PUBLIC_*` 값은 릴리즈에서도 살아있는 운영 env에 두도록 이동. 빌드 후 **번들에 값이 실제로 박혔는지까지 검증**하는 절차를 추가. (오배포 방지 장치가 만든 부작용을, 검증으로 되짚어 찾은 사례.)

## 3. 리퍼럴 딥링크가 특정 진입 경로에서 안 잡힘

- **증상**: 초대 링크로 앱은 열리는데 초대자(inviter)가 저장되지 않는 경우가 있었다.
- **진단**: 콜백에 무조건 로그를 찍어, `onDeepLink`이 **호출 자체가 안 된 것**을 확인. AppsFlyer의 UDL은 신규 설치(deferred) 귀속엔 강하지만, 직접(raw) 스킴 진입은 못 잡는 케이스가 있었다.
- **해결**: `expo-linking`으로 스킴 URL의 파라미터를 직접 파싱하는 **백업 경로**를 얹어(콜드/웜스타트 모두), 어느 경로로 들어와도 inviter가 유실되지 않게 이중화. → [`../code-excerpts/analytics.ts`](../code-excerpts/analytics.ts)

## 4. 동의 저장 403 — "백엔드 탓"으로 오진했다가 원인 재규명

- **증상**: 약관/알림 동의 저장이 403.
- **처음 진단(오진)**: "토큰이 안 붙었다"고 봤다.
- **실제 원인**: 그 시점은 **아직 계정이 없어** `/users/me/*` 자체를 못 치는 단계였다(토큰 유무 문제가 아님).
- **해결**: 동의를 가입 요청 body에 실어 보내고, 가입 후 best-effort로 재저장하는 **deploy-order-safe** 구조로 재설계. 백엔드 배포 순서에 무관하게 동작. → [`state-management.md`](./state-management.md)

## 5. 비ASCII 사용자 경로에서 Android 네이티브 빌드 크래시

- **증상**: 특정 개발 환경에서 릴리즈 빌드가 prefab/CMake 단계에서 IOException.
- **원인**: Gradle이 캐시/임시 디렉토리로 쓰는 사용자 홈 경로에 비ASCII 문자가 있으면 네이티브 툴체인이 경로를 깨뜨렸다. `local.properties`의 단일 백슬래시가 Java properties 파서에서 뭉개진 것도 겹쳤다.
- **해결**: Gradle 캐시/TEMP를 ASCII 경로로 강제하고, 경로는 슬래시로 정규화. 빌드 전 체크리스트에 편입해 재발 방지.

## 6. 관리자 사이드바 스크롤이 메뉴 클릭마다 최상단으로 리셋

- **원인**: 메뉴 선택을 `location.hash` 변경으로 처리했는데, 이게 fragment 네비게이션 → 라우터가 화면을 remount → ScrollView가 새로 만들어짐.
- **해결**: `history.pushState`로 바꿔 remount 없이 상태만 갱신하고, `popstate`/`hashchange` 리스너로 동기화. 스크롤 위치 보존.

## 7. 웹 초대 링크 복사가 http/LAN에서 안 됨

- **원인**: `navigator.clipboard`는 **보안 컨텍스트(https/localhost)에서만** 동작. LAN·http로 접속하면 `undefined`라 복사가 조용히 실패하는데 "복사됨"이라고 안내해 오해를 줬다.
- **해결**: 레거시 `execCommand('copy')` 폴백을 얹고, **실제 복사 성공 여부에 따라 안내 문구를 정직하게** 표기.
